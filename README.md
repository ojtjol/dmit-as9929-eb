## 先说清楚：AS9929 到底是啥

很多新手一上来就把 AS9929 和 AS4837 混为一谈，其实这俩虽都是中国联通的网络，但定位差着档次。

AS4837 是联通的普通骨干网，说白了就是"大众路线"，晚高峰一拥堵，跨太平洋延迟容易飙到 200ms 以上，丢包也不稀奇。而 AS9929 是联通的工业互联网骨干网（CUII，China Unicom Industrial Internet），属于联通掏了真金白银铺的精品线路，类似于电信 CN2 GIA 在联通那边的"对位产品"。它的特点是 hops 少、延迟低、晚高峰表现稳。

DMIT 这家 2017 年由几个在美中国留学生创立的服务商，从最早做 CN2 GIA 起家，这几年把 AS9929 也纳入了自家 Eyeball（EB）系列回程方案。简单理解：DMIT 的 Pro 系列主打电信 CN2 GIA 双向优化，EB 系列则是给联通和移动用户准备的"性价比款"，回程走 AS9929（联通）+ CMIN2（移动），电信方向在 LAX 节点最近也切到了 AS9929 与 CMIN2 混合负载。

## DMIT AS9929 实际跑起来怎么样

光说不练假把式。我从多个第三方实测里整理出的画面大概是这样的：

**晚高峰延迟**：LAX.EB 节点国内方向平均延迟在 140–160ms 之间，联通走 AS9929，移动走 CMIN2，电信在 AS9929 和 CMIN2 之间混合负载。这个数字放在跨太平洋精品线路里，属于"教科书级别"的稳。

**丢包率**：晚高峰基本控制在 0.1% 以下，不会出现那种一过晚上八点就卡成 PPT 的情况。

**硬件底子**：LAX.AN4 用的是 AMD EPYC 9004 系列（具体是 9654 之类的），LAX.AN5 升级到了 EPYC 9005。NVMe SSD，磁盘 IO 实测能稳定在 1GB/s 以上。KVM 虚拟化，CPU steal time 控制得不错，不会出现邻居吵到你睡不着的情况。

**IP 解锁**：原生 IP，Netflix、Disney+、ChatGPT 这些常用服务基本能解锁，适合做流媒体代理或者接 API 用。

**超量策略**：流量跑超之后不会直接断你网，而是降速到 4Mbps（TINY/Pocket/STARTER）或 8Mbps（MINI 及以上）。降速虽不快，但保你服务不断线，比直接停机厚道。
